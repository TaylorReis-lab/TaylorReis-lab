## Sobre mim

Sou desenvolvedor Full Stack, com experiência em desenvolvimento front-end e construção de aplicações que integram interfaces, APIs e bancos de dados.

Minha principal experiência está no ecossistema JavaScript e TypeScript, especialmente com React e Node.js. Também desenvolvo projetos com Python e estou ampliando meus conhecimentos em C# e .NET.

Gosto de resolver problemas práticos, escrever código de fácil manutenção e compreender como as diferentes partes de um sistema trabalham em conjunto.

**Áreas de interesse**
- Desenvolvimento Full Stack e backend.
- APIs REST, autenticação e integração de sistemas.
- Bancos de dados relacionais e NoSQL.
- Aplicações com inteligência artificial e automação.
- Arquitetura de software, testes e qualidade de código.

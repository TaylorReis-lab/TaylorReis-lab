## Sobre mim

Sou desenvolvedor Full Stack com experiência em desenvolvimento front-end e construção de aplicações que integram interfaces, APIs e bancos de dados.

Minha principal experiência está no ecossistema JavaScript e TypeScript, trabalhando com React e Node.js. Também desenvolvo projetos com Python e exploro C# e .NET para ampliar meus conhecimentos em desenvolvimento backend e aplicações desktop.

Gosto de entender o problema antes de implementar a solução, separar responsabilidades e construir software que possa ser mantido e evoluído.

**Áreas de interesse**
- Desenvolvimento Full Stack e backend.
- APIs REST, autenticação e integração entre sistemas.
- Bancos de dados relacionais e NoSQL.
- Ferramentas de inteligência artificial e automação.
- Arquitetura de software, testes e qualidade de código.
